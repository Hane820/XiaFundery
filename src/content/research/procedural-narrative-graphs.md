## Abstract

Branching narratives scale poorly: every added choice multiplies possible states. This preprint proposes a graph model in which nodes carry compact memory and relations, trading absolute branching freedom for authorial control and linear tooling. The model is validated qualitatively on the production pipeline of *Above the Deep*.
